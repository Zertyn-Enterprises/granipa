## Norte — PREMIUM (subido 2026-09-03 tarde)

El humano: *rediseño totalmente mejorado, se siente premium, como las apps más top del mercado. Cada detalle: tamaños, consistencia, colores, animaciones, abertura de popups, animaciones de dictado. Absolutamente todo.*

Barra: **Raycast** (popup spring, 8pt grid, cero ruido) + **Superwhisper** (overlay de dictado, waveform vivo, appear 260ms) + **Linear** (densidad, hairlines, type) + **Granola** (serif solo en título de página, calma).

No es un pase de `padding 8→6`. Si un cambio no se nota al lado de esas apps, no cuenta.

### Motion (contrato)

- Popup **open**: fade 0→1 + rise 12pt, 260ms, cubic (0.16, 1, 0.3, 1). `PanelMotion` en `System/PanelMotion.swift` — usadlo, no reinventéis.
- Popup **close**: 160ms ease-in. Reduce Motion = cut.
- SwiftUI interior: `.spring(response: 0.32, dampingFraction: 0.86)` para waveform, phase, hover. No `easeOut 0.08` en el overlay.
- Waveform: cada barra spring, no las 12 a la vez con un easeOut.

### Overlay de dictado (la feature bandera)

- Material ultraThin + corner **continuous 20**. Sombra suave, no caja opaca.
- Appear con `PanelMotion` (Grok lo cablea en el controller).
- Texto que llega con blur/opacity, no pop.
- Failed retryable: un botón Retry, no solo copy.
- Preparing no se siente “roto”: pulso del punto, no waveform muerto.

### Home / sidebar / detail

- Grid 4/8/12/16/24. Hit targets ≥ 28.
- Una acción primaria (Record). Quick note ghost.
- Filas 44–48pt, hover 4% white, radius 10.
- Transcript: type 15/22 leading, Me/Them con color de canal, no chrome extra.

### Settings

- Sin muros de caption. Una línea. Shortcuts es el único sitio de teclas.
- Segmented + grouped, no 7 paredes de texto.

## Qué está mal (verificado hoy, no redescubrir)

- Home: título serif + dos botones bordered + filas sin densidad. “Quick note” y “Record” compiten.
- Sidebar: Home y Dictation al mismo peso que folders.
- Settings: 7 tabs (Shortcuts nuevo). Extras tenía atajos duplicados — Grok los quitó; no los devuelvas.
- Dictation overlay y Recording HUD no parecen la misma familia (aunque hay `RecordingSharedViews`).
- Menu bar: lista larga (batería + dictate + record + captions + processing).
- Captions vs overlay de dictado: z-order / ruido.
- “Didn't catch that” / empty dictation sigue siendo un callejón.
- Charge limit ya funciona (icono de enchufe, no rayo). No tocar SMC/helper.

## Tickets

### Kimi — visual (barra premium, no nits)

1. **Theme.** Tokens ya hay (space/radius). Añade `Theme.spring` (response 0.32, damping 0.86) y úsalo. Cero `.system(size: 11/12/13)` suelto. Radius overlay = 20 continuous.
2. **DictationOverlayView + HUD + captions.** Misma familia: material, 20pt corner, type 15 medium para el texto vivo, waveform con spring por barra, hover ≥28. El controller de appear lo hace Grok con `PanelMotion`.
3. **Home + sidebar.** Record primary. Filas densas tipo Linear. Empty state 2 líneas.
4. **Meeting detail.** Transcript es el producto. Corta el auto-salto a Enhanced.
5. **ClipboardHistoryView + DictationHistoryView.** Mismo chrome que el overlay (material, radius, type). El panel appear lo hace Grok.
6. **Settings.** Caption de una línea. No toques el recorder de acordes.

`swift build` al terminar. No pises `AppState.swift` / `DictationController.swift` / Transcription.

### GLM — estados que la UI puede pintar

1. **Recording/processing.** Un estado que Home/HUD/menu puedan mostrar sin adivinar: recording / finishing / transcribing / enhancing / ready / failed. Si ya existe, expónlo limpio; no dejes `default: EmptyView()`.
2. **Dictation recovery.** Si el buffer queda vacío, el overlay tiene un retry de un golpe (el controller ya tiene atajo; conecta el estado, no rediseñes el panel).
3. **Captions.** `systemWarning` visible, no tapa el overlay de dictado, no se queda “hide forever” mal. Motor Muse: no rediseñes el protocolo.
4. Tests del contrato de estados si cambias el enum/public API.

`swift test` de tus suites. No pises `UI/Theme.swift` ni Settings.
